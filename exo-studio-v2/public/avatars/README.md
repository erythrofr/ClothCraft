# Avatar assets

`makehuman-base.obj` is the MakeHuman community base mesh. The mesh carries an explicit CC0 notice in the source asset and is staged here as the first detailed fitting-avatar visualization for Garment Studio.

Source: https://github.com/makehumancommunity/makehuman

The detailed mesh is currently visual only. Garment Studio continues to use its measurement-driven analytic body for collision while we build morph-target/mesh-collision support. Keeping those concerns separate prevents the render avatar from silently changing fit behavior.
