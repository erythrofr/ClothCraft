## Source mapping and implementation roadmap

`src/components/CloPropertyEditorAccordion.jsx` provides the selection-context shell; `docs/EXO_CLO3D_V2_PROPERTY_EDITOR_IMPLEMENTATION_20261016.md` documents its earlier implementation stage. The prime reports a newer EXO Fabric editor mirroring **Information / Material / Physical Property** and intentionally disabled independent face controls; this audit records that update without claiming a new EXO screenshot test. `docs/CLO3D_PROPERTY_EDITOR_DEEP_AUDIT_20261016.md` supplies the official-reference matrix and proposed acceptance cases. Earlier documents asserting no native visual evidence are superseded for **both** the blank context and the **selected Fabric** context described here.

1. **P0: empty-state parity.** In a V2 browser/native app QA session, select no object and compare the right property body against the new CLO capture; ensure no pattern-specific accordions or stale values leak into an empty selection. Distinguish the currently visible Fabric browser listing from active Fabric *property selection*. Preserve other project controls in their proper location.
2. **P0: complete live selected-context evidence.** **Fabric asset is now captured and partially mapped.** Continue scrolling its **Physical Property** group and inspect material Reflection subfields, face tab behavior and dropdown choices. Separately select whole pattern, edge, internal line, sewing pair and topstitch style/instance in an expendable CLO test project. Save screenshot and AX JSON *per state* and record exact labels, order, values, units and disabled conditions. Confirm build remains 7.0.242.
3. **P1: schema and parity.** Tie each selection kind to a typed field registry with `name`, `type`, `unit`, `range`, `readOnly`, `condition`, `capability` and native/draft command. Compare observed screenshots with rendered EXO selection states; prioritize pattern/edge/sewing/fabric before minor style contexts.
4. **P1: actual physical behavior.** Add solver-backed edge elastic, seam tape and fold/tension; then Bond/Skive/Solidify; verify native changes alter cloth behavior rather than only editor text. Add style-vs-instance separation for topstitch and hardware. Existing official reference ranges are candidates for validation, not proof of identical 7.0.242 defaults.
5. **P2: repeatable evidence.** Capture a side-by-side comparison per context with scale, platform, selection ID, active tool and accordion expansion; test edit, undo/redo, reload and unit conversions, including mixed selections and unavailable 3D mappings. Only then assign a version-specific parity score.

**Evidence limit:** A signed helper successfully selected the live **FABRIC 1** asset and captured the two approved screenshots; the audit reads those screenshots. CLO pattern, edge, sewing, topstitch and other selection contexts remain unobserved. No dropdown was expanded in the evidence, no independent face setting was changed, and the visible screenshots do not establish Physical Property coefficients.
