# Garment Studio — brand naming and .com research

**Research date:** October 14, 2026  
**Status:** Brand exploration only; no domains purchased, products renamed, or code changed.

## What the brand needs to mean

Garment Studio is intended to be an open, portable 2D/3D apparel development platform, not simply an AI fashion image generator or a garment-only Blender plugin. The current codebase spans pattern CAD, garment and body fit simulation, manufacturing exports, grading, materials, avatar support, and automation. Name the long-term platform independently of MIKRISTIAN and broadly enough to cover future desktop applications and tooling.

Brand criteria, in priority order: (1) short, recognizable .com; (2) distinctiveness from existing apparel/software brands; (3) pronounceable and spellable; (4) credible for both fashion creatives and technical patternmakers; (5) expandable to an open-source ecosystem; (6) strong simple wordmark/icon potential. Avoid implying functionality not yet validated or CLO3D equivalence.

## How domains were checked

We tested **210 candidate .com domains** against the authoritative Verisign .com RDAP endpoint `https://rdap.verisign.com/com/v1/domain/{domain}` on October 14, 2026. **132 returned an existing registration** and **78 returned HTTP 404 / no registry registration record**. A 404 is strong preliminary evidence that a registration is not currently present, **not confirmation that a domain is available to purchase**. Reserved, registry-premium, hold, registry policy, name changes, and timing can affect checkout. GoDaddy's v3 availability and live price API requires a personal access token; no authenticated GoDaddy availability/pricing confirmation was obtained. A user can check each name at `https://www.godaddy.com/domainsearch/find?domainToCheck=NAME.com` and should verify it again during checkout. Do not report a GoDaddy price without receiving an actual registrar quote.

## Names deprioritized after web collision screening

- **Seamvera**: already marketed as a seamless bra product, despite no .com registration record in this check.
- **Weftform**: already used as the name of a commercial rug product.
- **Draperyx**: listed as a previously designed commercial brand in an agency portfolio.
- **SeamAxis**: used as a sewing/quilting measuring tool name.
- **SeamFrame**: used in older scientific/software modeling work.
- **Drapeform**: older web records show a commercial site with that exact domain/name, while current .com RDAP returned no record; avoid without deeper due diligence.
- **Atelura**: existing genus of insects; possible search ambiguity.
- **Tessiform**: phonetically close to *Tessilform*, a fashion company name referenced in industry documents; additional diligence required.

These observations establish **search/discoverability concerns, not trademark ownership or infringement**. Run exact and phonetic trademark searches in the USPTO database, and check relevant jurisdictions and software/app-store/GitHub/social-media names before adoption.

## Suggested brand architecture

For a working example using the top name:

- **Texometry** — main company / open platform identity.
- **Texometry Studio** — 2D pattern + 3D garment desktop application (initially current Garment Studio).
- **Texometry Engine** — simulation, geometry and backend library family.
- **Texometry Patterns** — drafting / parametric patterns.
- **Texometry Manufacture** — tech pack, grading, markers and export workflows.

Possible positioning: **"From pattern to possibility."** Longer descriptor: **"Open garment design, simulation and production tools."** Keep the product description accurate to the capabilities currently validated and distinguish the project's present development status from its roadmap.

## Brand visual system

- A disciplined, primarily black/off-white neutral system with one measured signal color, rather than fashion-commerce pastel branding.
- Logo generated from pattern drafting anchor points, seam paths, and cloth meshes. One geometrically simple icon that remains identifiable at 16 px.
- A modern high-contrast wordmark with excellent readability. Optional technical mono for coordinates, measurements, and material labels.
- Visual motion draws from 2D pattern nodes deforming into fitted 3D forms; avoid proprietary CLO symbols or misleading physical fit demonstrations.

## Completion gate before buying or renaming

1. Open each finalist in GoDaddy or connect the official GoDaddy app and request an up-to-date domain availability and itemized **first-year, renewal, and premium** quote.
2. Complete US trademark and international/industry search; check lookalike pronunciation, existing companies, GitHub namespaces, package ecosystems, and social handles.
3. Score finalists on pronunciation with a nontechnical designer and a technical patternmaker; test the name alongside “Studio,” “Engine” and “Open Source.”
4. Select the name and register promptly if viable. Do not rename the code, repositories or website until a decision is explicitly approved.
