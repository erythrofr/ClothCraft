# Garment artwork editor: V2 handoff

The React editor is controlled through `ClothCraftGraphicEditor({graphics, onChange, panelId, panels, disabled})`. `graphics` is an array; `onChange(nextGraphics)` must persist it in the host garment document or local layout. `panels` accepts `{id, name}`. The selected `panelId` determines where each new image is placed. The host renderer must select graphics by exact panel ID before attaching them to each mesh.

`importGarmentArtwork(file)` accepts PNG, JPEG, or a restricted SVG subset, rasterizes through canvas, and resolves `{id,name,dataUrl,width,height,format}` with embedded PNG. It rejects files over 8 MB and raster dimensions over 16 million pixels or 8192 per axis. SVG scripts, style, foreign content, external links, and animation are stripped. Its output is display artwork, not a replacement for editable SVG paths.

`createGarmentGraphic(artwork, panelId)` creates default placement. `normalizeGarmentGraphic(record, {panels})` validates placement and embedded PNG data. `serializeGarmentGraphics(graphics)` creates a versioned JSON object; `deserializeGarmentGraphics(document,{panels})` restores validated records. The editor also exposes **Export artwork layout JSON**. JSON embeds PNG data and can be large; version 1 is not a native cloth solver document or print production interchange format.

`attachGarmentGraphics(panelMesh, panelGraphics)` attaches front and back overlays to a Three.js panel mesh with a UV attribute. `createGarmentGraphicOverlay(panelMesh, panelGraphics, {resolution,face})` builds a single overlay, and `disposeGarmentGraphicOverlays(overlays)` frees overlay resources when replacing the solver mesh. The overlay uses the mesh's current UV bounds and follows deforming geometry only when the host refreshes or updates the overlay geometry. UV maps must remain consistent from one solver frame to the next. `graphicPlacementInUV(record)` uses normalized center from the left/top of the panel rectangle and normalized width (`scale`). Graphic rotation is degrees in UI, mapped to radians for UV rendering. Placement on the editor's rectangular preview is an approximate UV layout; it does not claim manufacturing accuracy, pattern-piece clipping beyond the mesh triangles, physical ink simulation, or UV seam continuity.

Focused validation: `node scripts/check-garment-graphics.mjs`; production compilation: `npm run build`.
