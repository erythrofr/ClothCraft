# CLO toolbar correction — October 2026

Source: `references/clo-tool-index/manual/CLO_Creators_Field_Guide_Official.pdf`, pages 145–146. The official guide lists commands by tool family, not pixel-exact placement.

## 3D rail starting order

1. Simulate (working)
2. Simulation modes (existing auxiliary, not a CLO primary tool)
3. Select / Move (working)
4. Select Mesh (Box / Lasso / Brush) (planned, disabled)
5. Edit Styleline (planned, disabled)
6. Edit Sewing (sewing-guide viewing only)
7. Free Sewing (working)
8. Pin (existing manual pin action)

The first five named CLO commands are present in this sequence with the simulation-mode auxiliary placed after Simulate. This app does NOT yet implement Select Mesh or Edit Styleline.

## 2D reference strip A / B

The right-side toolbar remains 17 rows × 2 columns. The left 2D strip begins transform, points, curves, split, internal line; the other strip begins sewing correspondence, free sewing, seam weld (planned). Remaining 3D compatibility actions are retained beneath the sewing commands rather than silently deleted.

This remains a CLO-inspired mapping, not an exact reconstruction of every flyout slot.
