# EXO hanger assets

The five hanger tile images in `public/hangers/` are Blender renders generated by `scripts/generate-hanger-assets.py`. Wood and trouser-clip thumbnails are renders of the imported CC0 models used by their hover previews. Chrome, velvet and padded thumbnails are original procedural EXO geometry. The garment viewport and chrome/velvet/padded hover previews use procedural Three.js geometry via `createLibraryHanger3D`, with procedural fallback if a CC0 hover model fails to load.

## Performance

The sidebar's noninteractive hanger tiles use the pre-rendered static PNGs and create **zero WebGL contexts**. Hover detail previews still allow drag-to-rotate on an actual mesh. The Thomas hover model uses `public/avatars/preview/clo-thomas.glb` (approximately 1.2 MB), while fitting in the editor continues to use the original `public/avatars/clo-thomas.glb` (approximately 88 MB). The avatar preview refuses remote GLBs larger than 4 MB when their content length is provided.

## Verification

From the repository root, run `npm run clothcraft:dev` to serve port 5174, then `node docs/hanger-assets/qa-hanger-browser.mjs`. The browser fixture mounts the production `Library3DAssetPreview` and `LibraryAssetHover` components directly, without the heavy full-studio garment scene. The test checks that five thumbnail images decode without tile WebGL canvases, that all five hanger hovers display the expected imported/procedural real 3D geometry, that hover teardown removes each canvas, and that Thomas, Theo and Nora load from their small GLBs. Results are written to `qa-results.json` and an enlarged hover screenshot to `qa-hanger-panel.png`.
