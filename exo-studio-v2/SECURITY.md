# Security policy

EXO Sample 3D is an **experimental public source project**, not an accepted
production garment simulator. Do not post vulnerabilities, secrets, personal
information or private model files in public issues.

## Private vulnerability reporting

GitHub private vulnerability reporting is enabled for the official repository:

**[Report a vulnerability privately](https://github.com/mikristian/exo-sample-3d/security/advisories/new)**

Provide the affected revision, reproduction, expected security impact and a
non-sensitive minimal test. The maintainers will review the report privately
before discussing any fixes publicly. Never paste API keys, private garment
projects, customer records or exploit material into public issues.

## Supported release status

The current `main` branch is actively developed. Stable long-term support,
security patch SLAs and physical fit/factory certification have not been
established. Please disclose any security-sensitive data corruption, file
parsing, shell command, browser local-storage or backend network exposure
through private advisories rather than a public reproduction.
