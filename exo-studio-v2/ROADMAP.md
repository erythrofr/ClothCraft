# Roadmap

## Near term — open-source acceleration

- stabilize backend API and canonical simulation payload
- GarmentCode/PyGarment import/export and parametric generator bridge
- Blender document/scene bridge
- native PositionBasedDynamics XPBD garment backend
- benchmark browser vs native solver on tee/hoodie/pants
- expose backend selection without changing garment documents

## Simulation depth

- continuous cloth/body and cloth/cloth collision
- robust multilayer ordering and thickness
- anisotropic triangle strain/shear calibration
- production-grade bending and fold memory
- stable zippers, buttons, elastic, gather and bonded layers
- optional XRTailor/HOOD/ContourCraft services

## Pattern CAD

- cubic Bézier/NURBS paths
- darts, slash/spread, pleat design tools
- advanced trace/offset/merge/split
- measurement-driven blocks and parametric garment components
- industrial grading and ASTM/AAMA interoperability

## Avatar / fit

- parametric full-body morph model
- measurement extraction
- body scan import
- posture and skeletal animation
- pressure/ease/contact validation

## Production

- stronger polygon nesting / nap / grain constraints
- BOM and operation sheets
- factory annotations
- revision/change tracking
- PLM/ERP connectors

## Rendering / presentation

- Blender/Eevee/Cycles bridge
- studio/HDRI presets
- turntables and animation cache export
- textile microstructure/displacement/fuzz
